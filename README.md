# 部屋を借りるきまり（chintai-kimari）

エアコンがこわれたらだれが直す？出るときの壁紙の日焼けは？敷金はいくら返る？部屋を借りている人の場面を見て、民法（賃貸借）と借地借家法の決まりどおりの答えを選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/chintai-kimari/>

- 答えは、e-Gov 法令検索の民法（<https://laws.e-gov.go.jp/law/129AC0000000089>）第601条〜第622条の2と、借地借家法（<https://laws.e-gov.go.jp/law/403AC0000000090>）の条文（2026年11月17日に読みました）で確かめたことだけです。ふつうの傷みかどうかの例は、国土交通省「原状回復をめぐるトラブルとガイドライン」（<https://www.mlit.go.jp/jutakukentiku/house/jutakukentiku_house_tk3_000020.html>）の例に当てています。
- 人の名前・金額は作り話です。契約書の特約によって答えが変わることがあります。
- このゲームは法律の助言ではありません。公式の情報の代わりではありません。自分の場合どうなるかは、消費生活センター（消費者ホットライン188 <https://www.caa.go.jp/policies/policy/local_cooperation/local_consumer_administration/hotline/>）などに相談してください。
